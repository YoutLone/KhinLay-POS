# KhinLay-POS

Odoo 19 Community setup for Khin Lay. Staff take new orders in Odoo's built-in
**Point of Sale > Restaurant** register. The `restaurant_pos` addon keeps
recipes, ingredient tracking, expenses, reports, and historical custom orders.
The backend uses OCA Web Responsive with Khin Lay colors; the POS register keeps
Odoo's dedicated sales interface.
